# Radna soba 3D

3D tura radne sobe sa teretanom i sofom (glavni deo 300 × 240 cm, ulazni deo širok 130 cm), opremljene nameštajem iz IKEA Srbija.

- Prevuci za okretanje, točkić ili štipanje za zum.
- Režimi: spolja, odozgo i šetnja kroz sobu.
- Klikni na komad nameštaja da otvoriš njegovu stranicu na ikea.com/rs.

Sve je u jednom fajlu: `index.html` (three.js preko cdnjs).
